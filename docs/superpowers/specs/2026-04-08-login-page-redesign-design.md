# 登录页面 UI 改造设计文档

> 未来主义纯净风格 - 极简、高对比度、微妙动效

## 设计目标

打造大数据运维平台的专业形象，体现现代、可信赖、科技感的品牌调性。

参考风格：Stripe、Linear、Apple 登录页

---

## 一、整体布局与背景

### 布局
- 登录卡片垂直水平居中
- 卡片最大宽度 380px，内边距 48px
- Logo 上方，表单下方，紧凑排列

### 背景
- 深色渐变基底：
  - 左上：#0f0f23（深紫蓝）
  - 右下：#0a1628（深青）
  - 5个渐变节点平滑过渡
- 渐变流动动画：30秒周期，缓慢位移，产生呼吸感
- 无任何粒子、形状、气泡，纯渐变

### 卡片样式
- 背景：rgba(15, 23, 42, 0.03) — 几乎透明
- 边框：1px solid rgba(255, 255, 255, 0.06) — 极细
- 无阴影或仅保留一个极淡的 ambient shadow
- 无 blur 效果（区别于玻璃态）
- 圆角 16px

### 入场动画
- 卡片淡入 + 上移 10px，0.6s ease-out
- 无其他动态元素

### Logo 图标

- 渐变填充：品牌色(紫→青)

### 副标题
- "大数据运维智能平台"：13px
- 颜色：rgba(255, 255, 255, 0.5)

### 整体排列
- 全部居中对齐
- Logo 与标题间距：20px
- 品牌区与表单间距：36px

## 三、表单输入区域

### 输入框设计
- 无边框，无背景色
- 底部细线：1px solid rgba(255, 255, 255, 0.12)
- 获得焦点：底线变为品牌渐变色，轻微发光(阴影 0 0 8px)
- 内边距：上方 16px，下方 20px
- 文字颜色：纯白
- placeholder 颜色：rgba(255, 255, 255, 0.35)
- 字号：15px

### 图标
- 左侧图标：18px
- 颜色：rgba(255, 255, 255, 0.35)
- 获得焦点时变为品牌色 #8b5cf6

### 密码切换按钮
- 右侧眼睛图标保持
- 颜色与图标一致
- 点击时无背景变化，仅颜色变亮

### 输入框间距
- 每个输入框之间：24px

### 切换标签（登录/注册）
- 背景透明，无边框
- 未激活：rgba(255, 255, 255, 0.5)
- 激活：纯白 + 底部品牌渐变指示线(2px)

## 五、错误/成功提示与响应式

### 提示 Toast
- 位置：顶部中央，距顶 24px
- 圆角 10px，内边距 12px 20px
- 错误：rgba(239, 68, 68, 0.9) 背景
- 成功：rgba(34, 197, 94, 0.9) 背景
- 图标 16px，与文字间距 8px
- 动画：淡入淡出 + 下移 10px，0.3s

### 响应式适配（< 480px）
- 卡片内边距：32px，宽度 90%
- Logo 缩小：48px
- 标题字号：20px
- 输入框字号：保持 15px

## 技术实现要点

1. **渐变流动动画**：使用 CSS `@keyframes` + `background-position`，无需 JS
2. **输入框底线动画**：使用伪元素或 border-bottom + transition
3. **焦点发光**：box-shadow + transition，避免闪烁
4. **代码删除**：
   - 移除 `.floating-shapes` 和 `.shape` 浮动气泡
   - 移除 `.bg-gradient` 多层 radial-gradient
   - 移除卡片的 backdrop-filter: blur
   - 简化输入框样式，移除背景色和边框

## 设计决策记录

- **为什么选择方案 1**：最符合"未来主义纯净"方向，参考 Stripe/Linear/Apple，传达专业、可信赖、现代的品牌形象
- **为什么用渐变流动而非粒子**：粒子会破坏纯净感，渐变流动保持克制的同时增添生命感
- **为什么卡片近乎透明**：未来主义强调内容与背景的融合，而非传统卡片边界感
