## 前端设计

### 整体布局

```
┌─────────────────────────────┬──────────────────────┐
│   左侧动画面板（flex:1）     │  右侧登录卡片（420px）│
│   深蓝背景 + Lottie 角色    │  白色背景 + 表单      │
└─────────────────────────────┴──────────────────────┘
```

移动端（< 900px）：左侧折叠为顶部条幅，右侧全屏展示。

### 左侧动画面板

- **背景**：`linear-gradient(135deg, #0d1b4b 0%, #1a2f7a 100%)`
- **Lottie 动画**：3 个卡通角色，JSON 文件存放于 `frontend/public/lottie/`
- **鼠标交互**：监听 `mousemove`，计算鼠标在面板内的相对坐标，通过 `lottie.goToAndStop(frame, true)` 驱动每个角色到对应帧，实现"眼睛/身体跟随鼠标"效果
- **降级处理**：若 Lottie 加载失败，显示静态 SVG 几何图形

### 右侧登录卡片

- **容器**：白色背景，宽 420px，垂直居中
- **顶部 Logo**：紫色渐变机器人 SVG（内联，60×60px）
- **标题**：`大数据运维平台`（蓝色，`#1e40af`）+ 副标题 `Big Data SRE`
- **登录/注册 Tab**：保留现有 tab 切换逻辑
- **表单字段**（登录）：
  1. 邮箱输入框（带图标）
  2. 密码输入框（带显示/隐藏切换）
  3. 验证码行：左侧输入框 + 右侧 SVG 验证码图片（点击刷新）
- **表单字段**（注册）：
  1. 用户名
  2. 邮箱
  3. 密码
  4. 确认密码
  5. 验证码（同上）
- **登录按钮**：`#2563eb` 蓝色，全宽，`height: 46px`，圆角 8px
- **底部链接**：`忘记密码?` | `注册账号`
- **移除**：「记住我」勾选框、演示账号提示文字、登录页内的主题切换按钮（主题切换保留在主界面 header）

## 后端设计

### 新增接口：GET /api/auth/captcha

**响应**：
```json
{
  "captchaId": "uuid-xxxx",
  "svg": "<svg>...</svg>"
}
```

**实现**：
- 使用 `svg-captcha` 生成 4 位字母数字混合验证码
- 服务端用 `Map<captchaId, { answer, expireAt }>` 存储（内存，无需数据库）
- TTL：5 分钟，过期自动删除
- `captchaId` 使用 `crypto.randomUUID()`

### 修改接口：POST /api/auth/login

**新增 Body 字段**：
```json
{
  "email": "...",
  "password": "...",
  "captchaId": "uuid-xxxx",
  "captchaCode": "Ab3K"
}
```

**校验逻辑**（在现有密码校验之前）：
1. 检查 `captchaId` 和 `captchaCode` 是否存在
2. 查找 Map，未找到或已过期 → 返回 `400 验证码已过期，请刷新`
3. 大小写不敏感比对 → 不匹配返回 `400 验证码错误`
4. 校验通过后立即从 Map 删除（一次性）
5. 继续原有密码校验逻辑

### 修改接口：POST /api/auth/register

同上，注册也需要通过验证码校验（相同逻辑）。

## 错误处理

| 场景 | 处理方式 |
|------|---------|
| 验证码过期 | 返回 400，前端自动刷新验证码图片 |
| 验证码错误 | 返回 400，前端自动刷新验证码图片，清空验证码输入框 |
| Lottie 文件加载失败 | 静默降级，显示纯色背景 |
| 验证码接口失败 | 前端 toast 提示，保留重试按钮 |
